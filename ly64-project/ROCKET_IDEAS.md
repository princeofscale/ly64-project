# Идеи для улучшения Ракетки

## 🎯 Приоритетные фичи

### 1. Автовывод (Auto Cash-Out) ✅ В РАБОТЕ
Возможность установить целевой множитель, при котором автоматически выводятся средства.
- UI: чекбокс + input для целевого множителя в BetPanel
- Backend: сохранять autoCashOut в ставке, проверять при каждом тике
- UX: "Автовывод на 2.5x" — снижает стресс, позволяет отойти от экрана

### 2. Звуковые эффекты ✅ В РАБОТЕ
- Взлёт ракеты (whoosh)
- Тиканье множителя (subtle tick каждые 0.5x)
- Взрыв (boom)
- Успешный вывод (cha-ching)
- Проигрыш (sad trombone)
- Настройка громкости в UI

### 3. Статистика в реальном времени
Мини-график под историей раундов:
- Распределение последних 50 множителей (гистограмма)
- Средний множитель за сессию
- "Горячие" и "холодные" полосы
- Процент раундов >2x, >5x, >10x

### 4. История личных рекордов
Карточка "Топ-5 выводов":
- Лучший множитель
- Самый большой выигрыш в Ɍ
- Самая длинная серия выигрышей
- Анимация при побитии рекорда

## 🎨 Визуальные улучшения

### 5. Анимация взрыва ✅ В РАБОТЕ
Вместо простого fade:
- Particle explosion (осколки ракеты разлетаются)
- Screen shake эффект
- Красная вспышка по краям экрана
- Дымовой след остаётся на 1-2 секунды

### 6. Трейлы других игроков
Показывать полупрозрачные "призрачные" ракеты других игроков, которые вывели средства:
- Зелёная призрачная ракета останавливается на месте вывода
- Показывает username + множитель
- Исчезает через 2-3 секунды

### 7. Режим "Турбо"
Ускоренные раунды (5 сек ставки, быстрее растёт множитель):
- Переключатель в header
- Отдельная комната для турбо-режима
- Меньшие ставки, но больше раундов в час

## 🎮 Геймификация

### 8. Достижения (Achievements)
Система бейджей:
- 🚀 "Космонавт" — первый вывод на 5x
- 💎 "Алмазные руки" — вывод на 10x
- 🔥 "Огненная серия" — 5 выигрышей подряд
- 🎯 "Снайпер" — вывод ровно на 2.00x
- 💰 "Магнат" — заработать 100 Ɍ чистой прибыли

Показывать в профиле + уведомление при получении.

### 9. Режим "Двойная ставка"
Возможность поставить две независимые ставки в одном раунде:
- Одну вывести рано (безопасная)
- Вторую держать дольше (рискованная)
- UI: две колонки в BetPanel

### 10. Чат
Простой чат справа от игры:
- WebSocket real-time
- Эмодзи реакции на раунды
- Автосообщения: "🎉 @user вывел 8.5x!"
- Модерация (rate limit, фильтр мата)

## 🏆 Соревновательные фичи

### 11. Турниры
Еженедельные турниры:
- Призовой фонд из комиссии
- Таблица лидеров по прибыли за неделю
- Специальные бейджи победителям
- Countdown до конца турнира

### 12. Предсказание краша
Мини-игра перед раундом:
- Угадай диапазон краша (1-2x, 2-5x, 5-10x, 10x+)
- Небольшая ставка (0.1 Ɍ)
- Бонус если угадал (+0.3 Ɍ)
- Статистика точности предсказаний

## 🛠️ UX улучшения

### 13. Горячие клавиши
- Space — поставить/вывести
- 1-4 — быстрые ставки
- A — включить автовывод
- M — mute звуки

### 14. Мобильная оптимизация
- Вертикальная раскладка на телефонах
- Haptic feedback при выводе
- Полноэкранный режим
- Свайп для быстрых ставок

### 15. Режим "Наблюдатель"
Смотреть игру без ставок:
- Для новичков (изучить механику)
- Демо-режим без регистрации
- Показывать "Зарегистрируйся чтобы играть"

## 🎲 Экспериментальные идеи

### 16. NFT ракеты
Кастомные скины ракет:
- Покупка за Ɍ
- Редкие скины из лутбоксов
- Трейд между игроками
- Показывать скин в списке игроков

### 17. Режим "Луна"
Экстремальный режим:
- Множитель может расти до 100x+
- Но шанс краша выше
- Отдельная комната
- Легендарные выигрыши

### 18. Социальные фичи
- Добавить в друзья
- Копировать ставки друга
- Приватные комнаты для друзей
- Подарить Ɍ другу
